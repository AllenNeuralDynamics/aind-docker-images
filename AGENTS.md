# Agent instructions

Read `CONTRIBUTING.md` before changing an image or workflow; it holds the
conventions this repository follows.

- Build and smoke-test every image you change before calling it done.
- Never push to a Dependabot branch; steer its PRs with `@dependabot` comments.
- Check `.github/CODEOWNERS` before editing an image someone else owns, and
  flag changes to it rather than making them unasked.
